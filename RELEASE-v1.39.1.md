# AGNT v1.39.1 — Contact Property Details

Built directly from AGNT v1.39.0 Seller Intelligence.

## Changed

- Added Add Property Details beneath Add to Phone Contacts on every contact profile.
- Opens the seller property configuration in a dedicated full-viewport editor.
- After details exist, the action becomes Edit Property Details and shows the saved configuration.
- Removed property configuration from the general Edit Contact form.

## Preserved

- The property data remains on the existing unified contact record.
- Pipeline, MarketPulse close-match priority and sold-price estimates use the same saved fields.
- Buyer briefs, contact editing, Firebase, Firestore rules, authentication, UID separation and sync remain unchanged.
